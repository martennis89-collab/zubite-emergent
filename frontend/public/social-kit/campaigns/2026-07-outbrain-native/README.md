## Prompt set

All four images used the `ads-marketing` prompt class and requested premium, natural editorial photography in a crop-safe horizontal 3:2 composition. The shared visual constraints were:

- Bulgarian / contemporary European context
- warm off-white, charcoal, emerald `#007956`, and restrained orange `#FF6B00`
- candid people, natural skin texture, soft daylight, subtle film grain
- no text, letters, logos, watermarks, UI, shock tactics, mouth close-ups, visible conditions, procedures, before/after framing, arrows, or circles

The individual subjects were: a calm morning mirror routine; a parent and preteen after their morning routine; a patient and dentist in an equal consultation; and an informed reader in a quiet editorial setting.
